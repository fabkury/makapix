# Getting started with Makapix Club

Makapix Club is a community for sharing and enjoying pixel art, including animation. You do not need a physical display or programming experience to join.

## Explore the art

1. Open [Recommended](https://makapix.club/recommended) for the moderator-curated Promoted feed, or [Recent](https://makapix.club/) for recent artwork.
2. Select an artwork to see its full post, artist, description, and comments.
3. Visit the artist's profile to discover more of their work. Use [Search](https://makapix.club/search) to find more art.

You can browse public artwork without an account. [Create an account or log in](https://makapix.club/welcome) to share your own work, follow artists, react, and comment.

## Share your first artwork

1. Log in and open [Contribute](https://makapix.club/contribute).
2. Choose **Upload File** and select your artwork.
3. Add a title and a description. Include relevant hashtags to help people find it, and review the available license and sharing options.
4. Check the preview, then submit. Follow any validation or moderation messages shown by the site.

Share work you created or have permission to share. Credit collaborators and source material when appropriate.

### Prepare your artwork

| Property | Accepted values |
|----------|-----------------|
| File format | PNG, GIF, WebP, or BMP |
| Animation | GIF or animated WebP |
| File size | Default limit: 5 MiB (5,242,880 bytes); the upload form shows the site's current limit |
| Large canvases | Any width and height from 128 through 256 pixels, inclusive |
| Smaller canvases | The sizes listed below, including their rotated orientations |

If either side is below 128 pixels, use one of these sizes:

**8 × 8, 8 × 16, 8 × 32, 16 × 16, 16 × 32, 32 × 32, 32 × 64, 64 × 64, or 64 × 128.** Rectangular sizes also work with width and height swapped.

For example, 64 × 128 and 160 × 200 are accepted; 48 × 48 and 64 × 256 are not. Artwork does not have to be square.

If an upload fails, check the dimensions, actual file format, and file size against the message shown. Renaming a file extension does not convert the image.

## Bring art to a display

A **player** is a device that displays artwork from Makapix Club. **DIY makers** build or customize these displays using hardware such as an ESP32 or Raspberry Pi.

- To find a project to build, visit [player projects](https://makapix.club/players).
- To write player software, start with the [Player Device Guide](player/README.md). You can try its Python example on a computer before choosing hardware.
- To link a device you already have, follow its setup instructions to obtain a six-character code. Open your profile menu, choose **Manage Players**, then **Register Player**, and enter the code before it expires (15 minutes).

## Get help

Ask the community on [Discord](https://discord.gg/xk9umcujXV). For a reproducible website or player API bug, [open a GitHub issue](https://github.com/fabkury/makapix/issues) with the steps, expected result, and actual result. Keep passwords, device keys, and tokens out of screenshots and reports.
