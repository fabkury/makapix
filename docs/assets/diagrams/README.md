# Documentation diagrams

The `.mmd` files are the editable Mermaid sources for the matching `.svg` images.
The guides embed SVGs so GitHub displays them without interactive controls
covering labels on small screens. Each guide links to its diagram source.

These assets were rendered with Mermaid 10.9.3 and `mermaid-config.json`.
When updating a diagram, regenerate its SVG with that configuration and a white
background. Keep HTML labels disabled so the SVG uses portable text elements.
Check the result on GitHub at 320-pixel and desktop viewport widths. Keep labels
short, and describe the diagram in its image alt text and nearby prose.
